## 試作㉕で変更したこと

iPadで黒い画面のまま進まないとの報告に対応しました。旧実装はplay()が拒否された場合だけボタンを表示しており、再生要求が保留のまま応答しない場合に操作できませんでした。iPad側の生のイベントを取得したわけではなく、実機の直接原因は未確定です。

- 「タップして はじめる」をHTMLの時点から表示します。play()の結果やplayingイベントだけでは隠さず、再生位置が実際に進んだときだけ隠します。
- 再生要求が保留のままでも、表示中のボタンから再試行できます。止まっている際は黒い背景や映像部分のタップでも再試行します。
- 再生位置が約２秒進まなくなった場合や一時停止時は「タップして つづける」を再表示します。音声を勝手にミュートしたり、再試行のたびに先頭へ戻したりしません。

- MP4を再圧縮せずに再配置しました。映像と音声だけを残して付属サムネイルを除き、moov情報を先頭へ移動しました。元と映像／音声ストリームのSHA256はそれぞれ一致しています（ファイル全体のバイト列は変更）。

確認：全自動テスト通過。応答しないplay()、再生イベントだけ発生して再生位置が進まない状態、実際の進行、途中停止、再試行、背景タップ、スキップ、終了時の即時切り替えと重複防止、文字選択・開始まで確認しました。iPad実機での解消は未確認です。

### Pencilと指の入力
動画（約19.4秒）では、短い横画の後に「ひとふでで、ゆっくり…」「もうすこし さきまで…」という再試行表示が見られました。動画から生の入力イベントは得られないため、原因の確定はできません。次の関連し得る処理を修正しています。

- Pencil等の高頻度の小さな揺れで、線の長さが過大になることを防ぎます。判定用の線長測定だけ、460px基準の2px間隔を目安に位置をまとめます。描画と保存する筆跡はそのまま保持し、大きな往復・塗りつぶしは引き続き判定します。指・ペンに同じ基準を適用します。
- 合成された入力点を時刻順に処理し、既に処理済みの古い点を除きます。合成イベントに最後の位置が含まれない場合も、元イベントの位置を取り込みます。合成イベント取得が失敗した場合も通常の入力を記録します。
- ペンを離したイベントはキャンバス外も含めて文書で受け、１回だけ判定します。ポインター捕捉の解除だけで筆跡を破棄せず、本当のキャンセルとは区別します。
- ペンが接地から非接地へ変わったことが確認できる場合は、ホバー位置を筆跡に加えず、離した処理を補完します。元イベントの筆圧が0でも合成点に接地があれば、その接地を優先します。
- 指が先に触れていてもPencilの入力を優先し、別の指や手のひらのイベントを混ぜません。Pencilを離した直後350msの接触開始も抑えます。指だけの練習は引き続き使えます。
- 同じ寸法のresize通知では、書いている１画を消しません。練習エリア全体でタッチスクロールを抑え、手の接地でスクロールが始まりにくくしました。

イベント設計の参考：[W3C Pointer Events](https://www.w3.org/TR/pointerevents3/)と[合成イベントのAPI](https://developer.mozilla.org/en-US/docs/Web/API/PointerEvent/getCoalescedEvents)。Safari固有の不具合を実機で特定した、という意味ではありません。

- 同じ文字の「はじめ・そのころ・いま」を比較する専用画面。
- 初回・時期代表・お気に入りを組み合わせた容量管理、自動整理。
- 書き出しデータの読み込み、クラウド同期。
- 対応文字全体の検査・一覧の充実、教材データの版固定、未取得教材のオフライン利用。

流れる表示は中央の１文字、全体固定は選んだ文字の位置で書きます。同時に２か所へ書くことはできません。

## 検証

`node tests/regression.cjs` で、幾何判定・サイズ変更・非同期読み込み競合・パス記録・保存失敗・声かけの間隔・トランザクション確定の回帰検証を実行できます。外部パッケージは不要です。

`node tests/journey.cjs` で、縦横別の図案・線路選択、移動軸、移動完了待ち、動きを控える設定を検証できます。回帰検証にも、移動中の入力禁止・筆跡保持・移動先取得失敗を追加しました。

`node tests/fixed.cjs` は、実際のHTMLとアプリをテスト用DOMに読み込み、起動・各枠への最初の接点・１画判定・筆跡保持・保存位置・表示方式切り替え・教材要求の共有と同時数制限を検証します。実ブラウザーのレイアウトやタッチ処理を再現するものではありません。固定配置の収まりは `tests/journey.cjs` で検証します。

`node tests/diagnostics.cjs` は動作確認画面の実行・中止・書き出し・取得失敗を検証します。`node tests/real-strokes.cjs` は実データ63画の検証です。実データ検証用の依存をインストールする場合は、Node 22以降で `npm ci --ignore-scripts` を実行し、`npm test` で全検証を行えます。この開発用依存は静的アプリの起動には不要です。

JavaScript構文とHTMLの参照先も確認済みです。実際のブラウザー画面、IndexedDBの端末実装、iPad・Apple Pencilの描画感、音声再生、画面の縦横でのレイアウトは未検証です。上記検証はブラウザー動作確認の代わりにはなりません。
