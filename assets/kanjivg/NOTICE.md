# KanjiVG stroke data

Source: [KanjiVG official repository](https://github.com/KanjiVG/kanjivg), [project website](https://kanjivg.tagaini.net/).

Copyright Ulrich Apel and the copyright notices preserved in each SVG.
License: [Creative Commons Attribution-Share Alike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

The SVG files in this folder were downloaded unchanged on 2026-11-15. The manifest records the original URLs and SHA-256 hashes. No original stroke path has been redrawn or edited.

`stroke-data.js` extracts the original `d` attributes into a JavaScript data object for offline use and reproducible diagnostics. That derived stroke data is distributed under the same CC BY-SA 3.0 license. It is data, separate from the application logic.

The bundled subset contains 18 characters selected for regression/performance checks. It does not represent the complete KanjiVG dataset or guarantee support for other characters. The master URLs are retrieval provenance; the included hashes identify this exact snapshot.
